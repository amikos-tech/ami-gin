## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SIMD walk -> cleanup defer | A panic from JSON walking or a field transformer crosses into native document cleanup |
| SIMD adapter -> AddDocument | A failed close must cross as parserLifecycleError instead of an escaping panic that bypasses builder integrity policy |
| Tragic builder guard -> parser retry | A caller recovery boundary may attempt reuse, but terminal state must reject before the native parser is dispatched |

No new external trust boundary or package install is introduced; this plan changes only the existing tagged cleanup helper and its injected-callback regression.
