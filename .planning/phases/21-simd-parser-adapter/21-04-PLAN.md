Existing error-routing contracts:
  stageCallbackError.Unwrap() -> the hard stage error, including *IngestError
  softSkipDocumentError.Unwrap() -> the typed soft-skip cause, including errSkipDocument
  GINBuilder.Err() -> the first tragic error that permanently closes the builder
  GINBuilder.Finalize() -> nil whenever tragicErr is non-nil

Required lifecycle contract introduced by this plan:
  parserLifecycleError is package-private and identifies cleanup failures that make parser reuse unsafe
  errors.Is/errors.As traverse both the contextual cleanup error and an optional concurrent walk/stage error
  AddDocument recognizes this marker before every recoverable parser/stage branch and records one tragicErr

  Doc.Close failure leaves Doc.closed false and Parser.liveDoc set
  the next Parser.Parse returns ErrParserBusy while liveDoc remains set

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native document -> SIMD adapter | A failed native release leaves the upstream parser permanently busy and unsafe to reuse |
| Parser -> AddDocument policy | Fatal lifecycle failures cross a boundary that otherwise permits parser soft skips |
| Multi-cause error -> caller | Cleanup and staged-error causes must both survive wrappers for correct diagnosis and routing |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-21-13 | Tampering | high | AddDocument parser soft-mode routing | mitigate | Detect parserLifecycleError before every recoverable branch; blocking tests require a hard return, zero soft skips, and zero committed document state |
| T-21-14 | Denial of Service | high | Failed Doc.Close / ErrParserBusy reuse | mitigate | Store one tragicErr and reject every later AddDocument before parser dispatch; blocking test asserts parser and cleanup call counts stay at one |
| T-21-15 | Repudiation | high | Combined walk/stage plus cleanup error | mitigate | Multi-cause Unwrap preserves cleanup, stageCallbackError/softSkipDocumentError, IngestError, and sentinels through errors.Is/errors.As |
| T-21-16 | Denial of Service | medium | Duplicate or missed cleanup | mitigate | finishSIMDDocument owns one deferred cleanup callback; success/error tests assert exactly one invocation |
| T-21-SC | Tampering | low | Existing optional dependency graph | mitigate | No package change; retain exact v0.1.4 pin, tagged importer boundary, and `make simd-isolation-check` regression |
